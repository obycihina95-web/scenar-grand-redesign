# СКЭНАР-ГРАНД — концепция редизайна сайта

Концепция редизайна сайта центра СКЭНАР-терапии доктора Никитина (Калининград, [scenar-dok-s.ru](https://scenar-dok-s.ru/)).

**Задача:** у центра несколько направлений — лечение, диагностика, школа для домашних пользователей и магазин. Нужно, чтобы пациент быстро понял, с чего начать, и дошёл до записи.

**Что сделано**
- «Путь пациента»: консультация → диагностика → курс лечения → поддержка дома.
- Навигатор по симптомам: схема тела с точками, по клику — система организма и подходящие услуги.
- Голосовой поиск (Web Speech API) по услугам, симптомам, товарам и статьям.
- Отдельные страницы школы и магазина с фильтрами.
- Официальный прайс-лист с кодами медицинских услуг сохранён.
- Цвета, шрифт и фото бренда взяты с текущего сайта; адаптив до 375 px.

**Страницы:** главная, лечение и диагностика, школа, магазин, о центре и врачах, отзывы, прайс-лист, статьи, шаблон статьи, контакты, политика возврата.

Статический сайт: HTML, CSS и JS без сборки — откройте `index.html`.
